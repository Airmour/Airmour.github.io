## Gradle仓库
   在这里可以下载各版本的gradle https://services.gradle.org/distributions/ 
## Gradle环境变量
   将下载的gradle压缩包解压 配置到path中,就可以使用命令行编译项目 执行一些高级的操作
## 修改打包的路径和名称
```
//打包后应用名称
    applicationVariants.all { variant ->
        if (variant.buildType.name == 'release')
            variant.outputs.all { output ->
                outputFileName = "你的app_v${defaultConfig.versionName}.apk"
                //输出到项目的根目录的同级apk目录下
                variant.packageApplication.outputDirectory = new File(project.rootDir.parent + "/apk")
            }
    }
```
